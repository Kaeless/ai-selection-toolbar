# v0.3.0 更新说明

## 新增与调整

- 默认“解释”按钮改名为“了解”，用于快速掌握选中文字的含义；新增“详细解释”，用于分层说明背景、机制和术语。两个按钮使用不同的指令。
- 划词操作栏按按钮实际宽度排布，排除当前程序改为带提示的图标按钮。
- 点击操作后，结果窗以回答为主，移除占空间的程序来源、原文和演示控件。
- 回答支持常用 Markdown 排版，流式生成期间持续更新；历史仍保存原始文本。
- Windows 安装包、便携包和 EXE 版本号升级到 0.3.0，沿用原有设置、历史和笔记。

## 支持边界

详细解释可以要求模型给出可核验的参考方向，但软件不会联网检索或自动验证引文。输出中的具体来源仍须人工核对。目标应用是否能获取选区仍取决于 UI Automation 或标准 Edit 控件的支持情况。

## 验证与下载

等待 Windows CI 的编译、安装/卸载、启动和 SQLite 基础检查。Windows 7 SP1 x64、Windows 11 及目标软件的交互需要按[实机验收表](./WINDOWS-ACCEPTANCE.md)记录。
