# Windows 实机验收记录

## 已执行的 Windows CI 验证

`windows-2022` GitHub 托管运行器的 [v0.3 构建记录](https://github.com/Kaeless/ai-selection-toolbar/actions/runs/36220593415)已通过：

- Release x64 编译，以及便携 ZIP 和 Inno Setup 安装包构建。
- 便携版解压与安装包静默安装；两种目录中的 SQLite 原生库加载和数据库读写。
- 两种版本的 WPF 进程启动、本机管理页 HTTP 200、无令牌管理 API 返回 HTTP 401。
- 静默卸载后程序可执行文件被移除。

此运行器为 Windows Server 2022；这些结果不能代替 Windows 7 SP1 和 Windows 11 的桌面交互测试，也不能证明目标应用的选区行为。
