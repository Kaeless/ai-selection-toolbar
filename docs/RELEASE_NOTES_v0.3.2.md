# v0.3.2 更新说明

- 回答窗随输出内容调整宽度和高度；短回答不再占据大片空白，长回答达到屏幕边界后在窗内滚动。
- 流式请求现在识别模型的思考阶段并显示等待正文的提示；模型超时或只返回思考内容时，在回答窗直接显示原因，避免一直停留在“正在生成”。
- 详细解释的最长等待时间提高到 300 秒；等待期间可以随时点击“停止”，其他按钮仍使用原超时设置。
- 文字流更新同步进入界面，避免请求完成时仍有尚未处理的片段而丢失回答。
- 保持“了解”“详细解释”的原有提示词与用户设置；安装包和便携包版本为 0.3.2。

Windows CI 验证编译、打包、启动、SQLite 和安装卸载。回答窗的尺寸与模型接口实际延迟仍需在 Windows 桌面上验收。
